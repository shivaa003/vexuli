Three steps, no sign-up

Both people just need a browser. Nothing to install on either device.

  1. Create a room

    The sender picks Send and gets a 4-digit code. Add files or paste links while you wait.

  2. Enter the code

    The receiver picks Receive and types the code. The two browsers find each other and connect.

  3. Send

    Once the status turns green, press Send. Files arrive in the receiver's inbox, ready to download.

Your files never touch our server

Vexuli uses WebRTC. The server only introduces the two browsers; the transfer itself is a direct, encrypted connection between them.

  • Direct transferFile data goes from device to device. We don't receive it, store it or keep a copy.
  • Encrypted in transitWebRTC data channels are encrypted by default using DTLS.
  • Nothing to rememberRooms exist only while people are connected. Close the tab and the room is gone.

Good to know before you send

Direct transfer is simple and private, with a few trade-offs worth understanding.

Both tabs stay open

The transfer only works while both devices are online with Vexuli open. If either side closes the tab or loses connection, the transfer stops.

Large files use memory

The receiving browser holds the file in memory until you download it. Very large files may be slow or fail on phones and older computers.

Some networks block it

Strict firewalls and some corporate or school networks can stop direct connections. If pairing fails, try another network or a mobile hotspot.

Questions

Short answers to what people ask most.

Is there a file size limit?

Vexuli sets no limit itself, but the receiving browser has to hold the whole file in memory. Keep very large files to computers with plenty of RAM, or split them into archives.

Can someone guess my code?

A 4-digit code is easy to type but short, so treat it like a one-time pairing code. Only share it with the person you're sending to, and generate a new one with the refresh button once you're done.

Do I need an account?

No. There is nothing to sign up for and nothing to install. Open Vexuli on both devices and pair them with a code.

What can I send?

Any file type, several at once, plus web links. Links open in a new tab on the receiving device.

Why does the connection fail sometimes?

Direct connections depend on your network. Restrictive firewalls, VPNs and some mobile carriers can block them. Switching networks or turning off the VPN usually fixes it.
